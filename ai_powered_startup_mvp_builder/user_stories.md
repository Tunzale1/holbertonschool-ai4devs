# User Stories – Plastic2Future AZ

## User Story 1 – Find Collection Points
As a resident, I want to view nearby plastic collection points on a map so that I can find convenient locations to recycle plastic waste.

## User Story 2 – Identify Plastic Waste
As a resident, I want to upload a photo of plastic waste so that the AI system can identify its likely plastic type and recycling category.

## User Story 3 – Track Plastic Collection
As a resident, I want to record the amount of plastic I have collected so that I can monitor my personal recycling contribution.

## User Story 4 – View Environmental Impact
As a resident, I want to view statistics about collected and recycled plastic so that I can understand the environmental impact of my activities.

## User Story 5 – Register as a Collector
As a waste collector, I want to create a profile so that recycling businesses can identify and contact me.

## User Story 6 – Publish Available Plastic
As a waste collector, I want to publish listings containing plastic type, quantity, and location so that recycling businesses can find available recyclable materials.

## User Story 7 – Browse Recyclable Materials
As a recycling business, I want to browse available plastic listings so that I can find recyclable materials that meet my requirements.

## User Story 8 – Contact Collectors
As a recycling business, I want to view contact information provided by collectors so that I can discuss potential material collection arrangements.

## User Story 9 – Manage Collection Points
As a platform administrator, I want to add, update, and remove collection point information so that residents can access accurate recycling locations.

## User Story 10 – Monitor Platform Activity
As a platform administrator, I want to view overall collection statistics and marketplace activity so that I can monitor platform performance and engagement.

---

## MVP Priorities

### High Priority
- Find plastic collection points.
- Upload images for AI plastic identification.
- Record collected plastic quantities.
- View environmental impact statistics.

### Medium Priority
- Publish recyclable plastic listings.
- Browse available materials.
- Contact waste collectors.

### Low Priority
- Advanced administrator analytics.
- Additional marketplace management capabilities.

## Notes
- The initial release will focus on Baku, Azerbaijan.
- The first version will be a web application.
- User authentication may be excluded from the initial prototype.
- AI identification results are estimates and should not be treated as certified material classifications.
