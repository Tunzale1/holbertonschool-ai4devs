# Bug Regression Testing Prompt Template

**Role**: Senior Quality Assurance Engineer

**Task**: Develop regression tests to verify that previously fixed bugs remain resolved and that recent code changes have not introduced new problems.

**Input Placeholder**:
- [BUG_DESCRIPTION]
- [PREVIOUS_BUGGY_CODE]
- [UPDATED_CODE]
- [EXPECTED_BEHAVIOR]

**Expected Output**:
1. Regression test cases.
2. Automated test code where appropriate.
3. Expected results for each test.
4. Instructions for executing the tests.
5. Summary of potential regression risks.
