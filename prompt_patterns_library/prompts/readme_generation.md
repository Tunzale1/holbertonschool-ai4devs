# README Generation Prompt Template

**Role**: Open-Source Documentation Specialist

**Task**: Generate a professional README.md file for the software project using the provided project information.

**Input Placeholder**:
- [PROJECT_NAME]
- [PROJECT_DESCRIPTION]
- [PROJECT_FEATURES]
- [INSTALLATION_INSTRUCTIONS]
- [USAGE_EXAMPLES]

**Expected Output**:
A complete README.md containing:
1. Project title and description.
2. Main features.
3. Installation instructions.
4. Usage examples.
5. Requirements and dependencies.
6. Contribution guidelines.
